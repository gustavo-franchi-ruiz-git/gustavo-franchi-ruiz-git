# Hi, I'm Gustavo 👋

Developer working across the stack with **C#**, **Node.js** and **React**.
I like building software that solves real problems, and most of my projects started as tools for my own day-to-day life or for my family.

### 🛠️ What I'm building

- **Cond-Ops** — a work order app for residential condominiums, plus its landing page *(TypeScript)*
- **controlFinan** — a personal finance tracker *(TypeScript)*
- **Spaced Repetition** — a study app based on spaced repetition, with the back end in C# *(C# / .NET)*

> These repositories are private. I'm happy to walk through the code or show a demo, just reach out.
